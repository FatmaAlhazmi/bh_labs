# BH geodesics & scattering (Mathematica notebooks)

A small Mathematica/Wolfram Language notebook collection for exploring:

- **Kerr black hole** motion / trajectories (interactive + scans)
- **Schwarzschild scattering** experiments (lab-style notebook)

## Quick start

1. Open a notebook in **Wolfram Mathematica** (or **Wolfram Player** if it supports the features you use).
2. Run the initialization / definitions cells near the top.
3. Run the “Quick Start” / example cells at the bottom.

Tip: If something looks empty (like a Poincaré section), increase the integration time:
- increase `tauMax`
- increase `nSample`
